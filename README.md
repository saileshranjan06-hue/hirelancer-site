# Hirelancer.agency Website

Portfolio website for Hirelancer.agency — a static site (HTML/CSS/JS, no build step required).

## Structure
- `index.html` — Home
- `how-it-works.html` — Process page
- `sectors.html` — Industries covered
- `pricing.html` — Pricing page
- `about.html` — About page
- `contact.html` — Contact / hire request form
- `styles.css` — Shared styles (brand color #ea312c)
- `script.js` — Mobile nav toggle

## Deploy
This is a static site — Vercel will detect it automatically with no build command needed.
1. Push this repo to GitHub.
2. In Vercel: New Project → Import this repo → Framework Preset: "Other" → Deploy.
3. Add your custom domain under Project Settings → Domains.

## Editing
Edit the `.html` / `.css` files directly, commit, and push — Vercel will auto-redeploy on every push to the main branch.
